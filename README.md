# HireLens

AI-Powered Recruitment Intelligence Platform

HireLens is a full-stack AI recruitment platform that helps recruiters
analyze resumes against job descriptions using explainable,
evidence-backed candidate intelligence.

## Project Status

Day 1 - Project Foundation

## Planned Technology

- Frontend: Next.js + TypeScript + Tailwind CSS
- Backend: Python + FastAPI
- Database: PostgreSQL + pgvector
- Cache/Queue: Redis
- AI/NLP: Python + LLM + Embeddings
- Storage: S3-compatible private storage
- Deployment: Docker

## Core Principle

HireLens provides AI-assisted recruitment intelligence while keeping
the final hiring decision under human control.
